# 灰の塔 ゲームコア

戦闘状態、ターン処理、カード効果の解決など、ゲームの根幹となる実装を管理します。このフォルダはプロジェクトのルートGitリポジトリで他のファイルと一緒に管理します。

現在のブラウザ版は `combat.js` を `window.GameCombat` として公開し、コンテンツ定義を `window.GameContent` から読み取ります。配信時には `index.html` とこのフォルダのランタイムファイルを同じサイト構成に組み合わせます。

注意: Gitリポジトリを非公開にしても、ブラウザへ配信したJavaScriptは閲覧・取得できます。実行ロジック自体の秘匿が必要になった場合は、サーバー側処理へ移す必要があります。
