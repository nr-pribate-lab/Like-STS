# 灰の塔 — 一歩目

デッキ構築型ローグライクの最小プレイ可能プロトタイプです。ブラウザ標準の HTML / CSS / JavaScript のみで動作し、ビルド工程や外部ライブラリ、外部アセットへの通信を必要としません。

## 起動方法

`index.html` をブラウザで直接開くか、静的Webサーバーから配信してください。どちらの方法でも動作します。

## 遊び方

- タイトルで「旅を始める」を押し、町のメニューから「冒険」を選びます。
- ダンジョン「灰の回廊」とキャラクター「灰路の剣士」または「夜血の眷属」を選び、「冒険を始める」で戦闘に進みます。
- 町の「強化」「交流」は後から編集できる仮画面です。
- 初期デッキは「斬撃」5枚、「防御」5枚。戦闘開始時に順番をシャッフルします。
- 所持金は100$から始まり、村や途中のショップでアイテムを購入できます。「回復薬」は40$で、戦闘中に使うと体力を最大20回復します。
- ショップで「集中」を選ぶと、ラン中のデッキに1枚追加され、以降の戦闘は11枚になります。
- 斬撃は1エネルギーを使い、灰守りに6ダメージを与えます。防御はブロックを得て、集中はブロックとドロー、ゾーンは一時的な筋力を得ます。
- 夜血の眷属は吸血で体力を回復し、蝙蝠を召喚して攻撃や回復に使います。
- 「血蝠の契約」は永続カードです。使用後、次の自分のターン開始からHPを1失い、蝙蝠を1体召喚します。
- 戦闘に勝つと20$のゴールド報酬とカード報酬を受け取れます。アイテムは25%の確率で候補に加わり、カードは3候補から選びます。
- 1ターンに3エネルギー。敵のHPは30、反撃は6ダメージです。
- 手札を使ったら「ターン終了」を押します。山札が空になると捨て札をシャッフルします。
- 勝利後は報酬を受け取ってマップへ戻ります。敗北すると町へ戻ります。

## 構成とGit方針

プロジェクト全体（`game-core/` を含む）をこのルートの単一Gitリポジトリで管理します。公開先はまだ設定していません。Gitリモートが必要になった時点で、公開先を決めてから設定してください。

```text
content/
  shared/
    effects/            カードなどから呼び出す共通効果スクリプト
    map-nodes/          ステージから参照する地点定義
    stages/             ステージ定義
    enemies/            共通の敵定義
    relics/             共通のレリック定義
    items/              共通のアイテム定義と使用処理
  characters/
    <character-id>/
      character.js      キャラクター定義
      cards/            このキャラクター専用のカード定義
game-core/              戦闘とゲームルール
src/main.js             画面遷移とUI
src/boot.js             マニフェストに基づくコンテンツ読み込み
content/manifest.js     コンテンツファイル一覧
index.html              画面構造
styles.css              戦闘画面の表示
screens.css             タイトル、町、冒険準備画面
build.ps1               コアとコンテンツを配信用に組み立てる
```

コンテンツ定義はJavaScriptで記述します。カード定義はキャラクター固有なので、各キャラクターの `cards/` に置き、`GameContent.characters[characterId].cards[cardId]` に登録します。ステージ、地点、敵、レリック、共通効果スクリプトは `content/shared/` 以下で管理します。ステージは地点IDを配列で参照し、地点は敵IDなどを参照します。起動時にID参照を検証し、参照先がなければ起動エラーを表示します。現在のマップは一本道で、地点を円形アイコン、右上に凡例として表示します。最後の最終ボス戦は未実装です。新しい効果は `window.GameContentEffects[effectId]` に関数を登録し、`content/manifest.js` の `shared.effects` に追加します。カードの効果配列はゲームコアが順番に呼び出します。詳細は `content/shared/effects/README.md` を参照してください。

`build.ps1` を実行して `dist/` を作成します。プロジェクトのチェックアウトだけでビルドできます。

## AWS S3 配信

本作は静的ファイルだけで構成されているため、S3 の静的サイト配信に適しています。`build.ps1` が作成する `dist/` の中身を配信します。Git管理用ファイルや `.git` フォルダはアップロード対象にしません。HTTPS 配信や独自ドメインが必要な公開環境では、S3 をオリジンとする CloudFront の利用を想定します。

```text
dist/index.html
dist/styles.css
dist/screens.css
dist/src/boot.js
dist/src/main.js
dist/game-core/combat.js
dist/content/shared/...
dist/content/characters/<character-id>/...
```

ブラウザへ配信するJavaScriptは利用者が取得できます。

## MVPの範囲

- キャラクター1人、区画1つ、ステージ1つ、カード1種類、通常敵1種類。
- タイトル、町メニュー、冒険準備、戦闘、結果後の町への帰還までの流れ。
- 報酬、イベント、商店、レリック、セーブ、複数ステージは未実装。
- 見た目は CSS で描画し、画像ファイルを使わずに配信できる構成。
