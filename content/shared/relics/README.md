# 共通レリック

全キャラクターで共有するレリックの定義を配置します。キャラクター限定レリックの配置場所と登録先は未決定です。

レリックには全コンテンツで一意な `id`、表示名 `name`、説明 `description` に加え、キャラクター限定か共通かを示す情報を設定します。効果はレリックごとの説明文に記載し、発動タイミングは任意です。同じレリックは重複して所持できません。取得方法は強敵の撃破、ショップでの購入、イベントです。

説明文はプレイヤー向けのルール説明です。実際の効果はコンテンツ側の別JavaScriptハンドラーで実行し、レリックIDに対応付けます。発動イベントは「戦闘開始」「プレイヤーターン開始」「カード使用」「ダメージを受けたとき」「敵撃破」「戦闘勝利」です。該当イベントが起きるたび、所持レリックの順に毎回発動します。発動時の個別表示や演出は行いません。キャラクター限定レリックの配置場所・登録先は未決定です。

パワーベルト（`relic_power_belt`）を例として登録済みです。共通レリックで、ショップ入手、効果は筋力+2です。ハンドラーは `content/shared/relics/power-belt.js` にあります。仮設ショップで無料取得でき、次の戦闘が終わると失います。通貨・価格つきの商品購入と、複数戦闘にわたる所持管理は未実装です。戦闘コアは `createRun(enemyId, random, relicIds)` の第3引数に所持レリックIDを渡すと、戦闘開始時ハンドラーを呼び出します。
