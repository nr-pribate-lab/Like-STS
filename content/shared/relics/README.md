# 共通レリック

共通レリックの定義を配置します。キャラクター限定レリックは同じID空間を使い、定義に `characterId` を指定します。

レリックには全コンテンツで一意な `id`、表示名 `name`、説明 `description` に加え、キャラクター限定か共通かを示す情報を設定します。効果はレリックごとの説明文に記載し、発動タイミングは任意です。同じレリックは重複して所持できません。取得方法は強敵の撃破、ショップでの購入、イベントです。

説明文はプレイヤー向けのルール説明です。実際の効果はコンテンツ側の別JavaScriptハンドラーで実行し、レリックIDに対応付けます。発動イベントは「戦闘開始」「プレイヤーターン開始」「カード使用」「ダメージを受けたとき」「敵撃破」「戦闘勝利」です。該当イベントが起きるたび、所持レリックの順に毎回発動します。発動時の個別表示や演出は行いません。

共通レリックを追加しました。旅人の小袋はアイテム枠+1、初手の火花は各ターン最初の攻撃カードでエネルギー+1、静謐のしおりは各ターン最初のスキルカードで1枚ドロー、三拍子の珠は各ターン3枚目ごとのカードでエネルギー+1、守り糸は防御カード使用時に3ブロック、灰蜜の小瓶は各ターン最初のHPダメージ時にHPを2回復、金箔の印章は戦闘報酬ゴールド+10、残光の灯はHP半分以下で戦闘開始時に1ドローとエネルギー+1です。いずれも共通レリックとしてショップ・イベント・強敵報酬に出現します。

パワーベルト（`relic_power_belt`）は戦闘中の筋力+2、熾火の護符（`relic_ember_ward`）は戦闘開始時に6ブロック、先制の火種（`relic_first_flame`）は戦闘開始時にこのターンのエネルギー+1、先見の羅針盤（`relic_foresight_compass`）は戦闘開始時に追加で1枚ドローします。いずれも共通レリックで、ショップ・イベント・強敵勝利報酬から入手できます。強敵報酬は未所持レリックからランダムに1つ選び、すべて所持済みの場合は50ゴールドを代わりに得ます。鍛火の紋章（`relic_swordsman_forge`）と月蝠の護符（`relic_nightborn_moonbat`）は、それぞれ灰路の剣士・夜血の眷属専用です。刃鳴りの構え（`relic_swordsman_edge_echo`）は防御使用時に手札の斬撃を防御値+2へ、返し刃の構え（`relic_swordsman_guard_echo`）は斬撃使用時に手札の防御を斬撃値+2へ変えます。いずれも強化ツリー解放後、対応キャラクターのショップと強敵報酬に加わります。ハンドラーは各レリックIDに対応する `content/shared/relics/` 内のJavaScriptファイルです。
